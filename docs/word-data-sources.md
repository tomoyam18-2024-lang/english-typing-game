# Word Master Data Sources

This project keeps the word-selection master list separate from the game runtime data. The generated master list is written to:

```text
src/data/wordMaster.json
```

It does not include Japanese definitions and is not connected to `src/data/words.ts`.

## Commands

Download official source files:

```text
pnpm download:word-master
```

Generate and validate the 2,500-word master list:

```text
pnpm generate:word-master
```

Generate the non-destructive advanced-quality V2 master list:

```text
pnpm word
```

Audit the generated master list before adding Japanese definitions:

```text
pnpm word:audit
```

Generate a conservative cleanup review without modifying `wordMaster.json`:

```text
pnpm word:cleanup-review
```

Extract a 50-word Japanese WordNet sample without modifying game data:

```text
pnpm word:wordnet-sample
```

Compare the same 50-word sample with Japanese WordNet plus Japanese Wiktionary data:

```text
pnpm word:multi-dictionary-sample
```

Generate the full 2,500-word review dictionary without connecting it to the game runtime:

```text
pnpm word:generate-dictionary
```

The generator reads only local files from `data/word-master/raw/`, so repeated runs are deterministic for the same input files.

## App Levels

These are internal app levels only. They do not claim any official TOEIC, TOEFL, CEFR, or test-score alignment.

- Level 1: Business Advanced, target 700 words.
- Level 2: Advanced, target 800 words.
- Level 3: Academic Advanced, target 1,000 words.

## Selection Rules

The script normalizes words to lowercase, removes duplicates, excludes spaces, hyphens, digits, non-ASCII alphabetic tokens, obvious all-caps abbreviations, and a small set of proper-like calendar words.

No automatic stemming is applied. The NGSL Project lists are treated as ranked headword/flemma lists, which avoids unsafe merges of words that only look morphologically related.

Level assignment:

1. Level 1 takes the first 700 valid unique TSL words by TSL rank.
2. Level 2 takes up to 550 additional TSL words, then fills to 800 with the highest-ranked unused NAWL words.
3. Level 3 takes unused NAWL words first, then fills to 1,000 with unused NGSL-GR words.

Every generated entry keeps all source memberships and ranks found across the imported lists:

```json
{
  "word": "substantial",
  "level": 2,
  "sources": [
    { "name": "TSL", "rank": 530 },
    { "name": "NAWL", "rank": 120 }
  ]
}
```

Validation output is printed to the console and a detailed report is written to:

```text
data/word-master/reports/wordMasterReport.json
```

## Word Master V2 Selection

The V2 master list is generated by:

```text
pnpm word
```

Output:

```text
src/data/wordMasterV2.json
src/data/generated/wordDictionaryV2Reusable.json
data/word-master/reports/wordMasterV2Report.json
reports/removed-from-master.csv
reports/new-words-needing-dictionary-data.csv
reports/new-words-needing-dictionary-data.json
reports/master-v2-level-samples.csv
```

V2 is intentionally non-destructive. It does not rewrite `src/data/wordMaster.json`, does not delete existing dictionary data, and does not connect the generated data to the game runtime.

Selection policy:

1. Use TSL 1.2, NAWL 1.2, and BSL 1.2 as primary supply sources.
2. Use NGSL 1.2 core as an exclusion and audit set so core high-frequency words such as function words and basic numerals do not enter the advanced master.
3. Do not use NGSL-GR as a primary backfill source for V2.
4. Treat level sizes as caps, not fixed quotas. The generator does not backfill from lower-quality sources to force exactly 2,500 words.
5. Keep source memberships and ranks for all TSL/NAWL/BSL memberships found for each selected word.

V2 app levels remain internal app labels only:

- Level 1: Business Advanced, TSL-centered, capped at 700 words.
- Level 2: Advanced, remaining TSL plus BSL, capped at 800 words.
- Level 3: Academic Advanced, NAWL-centered, capped at 1,000 words.

Cleanup review output is written to:

```text
reports/word-cleanup-review.csv
reports/word-cleanup-replacements.csv
```

The cleanup review is intentionally non-destructive. It does not connect Japanese WordNet, does not generate Japanese definitions, and does not rewrite the master list.

## Japanese WordNet Sample Extraction

Japanese definition work starts with a non-destructive 50-word sample:

```text
reports/wordnet-sample.json
reports/wordnet-sample.csv
reports/wordnet-primary-review.csv
reports/wordnet-primary-comparison.csv
```

The sample script reads `src/data/wordMaster.json`, selects words deterministically across Level 1 / Level 2 / Level 3, inspects the SQLite schema at runtime, and then extracts:

- English lemma to WordNet synsets.
- Japanese lemmas attached to the same synsets.
- Japanese gloss text for review context.
- Grouped `meanings` for all Japanese lemmas.
- Synset-level heuristic `primaryMeaningCandidates` for game display review.

`primaryMeaningCandidates` are not final production meanings. Each candidate represents one synset, and selected Japanese lemmas inside that synset are treated as near-synonyms for one display line. Japanese WordNet v1.1 does not provide a reliable app-specific sense-frequency signal for this game, so the script uses conservative heuristics: available sense rank and tag-count/frequency fields when present, part-of-speech diversity, concise Japanese lemmas, and lower priority for very long, symbol-like, negated, or overly specialized-looking lemmas. All extracted synsets and raw lemmas remain in the JSON report.

### Japanese WordNet Local Files

The official SQLite distribution is:

```text
wnjpn.db.gz
```

Place either of these files locally:

```text
data/wordnet/wnjpn.db
data/wordnet/wnjpn.db.gz
```

If only `wnjpn.db.gz` exists, `pnpm word:wordnet-sample` streams it through gzip and creates `data/wordnet/wnjpn.db` before reading it. Both files are ignored by Git.

Official source:

```text
https://bond-lab.github.io/wnja/eng/downloads.html
https://github.com/bond-lab/wnja/releases/download/v1.1/wnjpn.db.gz
```

## Japanese Wiktionary Multi-Dictionary Sample

Japanese Wiktionary is used only as a second-source ranking signal for the same 50-word sample. It is not connected to the game runtime and does not replace `src/data/words.ts`.

The script reads local Kaikki/Wiktextract JSONL data:

```text
data/wiktionary/kaikki-jawiktionary-english.jsonl
data/wiktionary/kaikki-jawiktionary-english.jsonl.gz
```

Run:

```text
pnpm word:multi-dictionary-sample
```

Outputs:

```text
reports/multi-dictionary-sample.json
reports/multi-dictionary-review.csv
reports/multi-dictionary-comparison.csv
```

The script keeps Japanese WordNet synsets and raw Japanese lemmas intact. Japanese Wiktionary glosses are used to improve primary-meaning ranking through POS agreement, Wiktionary sense order, and Japanese wording overlap. Sense alignment is heuristic; if WordNet and Wiktionary cannot be confidently aligned, the result is flagged for human review rather than forced into a one-to-one mapping.

### Japanese Wiktionary Local Files

Use machine-readable data for Japanese Wiktionary entries whose language is English (`英語`). The local test file can be downloaded from the Kaikki.org Japanese Wiktionary English dictionary page:

```text
https://kaikki.org/jawiktionary/%E8%8B%B1%E8%AA%9E/index.html
```

Alternative source data can be produced from the official Wikimedia Japanese Wiktionary dump with Wiktextract, or taken from Kaikki's raw Wiktextract downloads:

```text
https://dumps.wikimedia.org/jawiktionary/
https://kaikki.org/dictionary/rawdata.html
```

Do not commit these raw files. The project ignores `data/wiktionary/*.jsonl`, `*.jsonl.gz`, `*.ndjson`, and `*.ndjson.gz`.

## Full Generated Dictionary Review Data

The 2,500-word dictionary generation step expands the same Japanese WordNet + Japanese Wiktionary logic to every word in `src/data/wordMaster.json`.

Run:

```text
pnpm word:generate-dictionary
```

Outputs:

```text
src/data/generated/wordDictionary.json
reports/full-dictionary-review.csv
reports/low-confidence-words.csv
reports/missing-japanese-meanings.csv
reports/full-dictionary-summary.json
```

This generated dictionary is intentionally separate from the game runtime:

- It does not modify `src/data/words.ts`.
- It is not imported by the game UI.
- It does not add level-selection UI or any gameplay changes.
- It does not use Weblio, Google Translate, AI-generated Japanese definitions, or any inferred dictionary information.

Each generated word keeps the original master-list `word`, `level`, and `sources`, plus dictionary-derived review data:

```json
{
  "word": "allocate",
  "level": 2,
  "sources": [{ "name": "TSL", "rank": 530 }],
  "meanings": [],
  "primaryMeanings": [
    {
      "pos": "verb",
      "definitions": ["割り当てる", "配分する"],
      "sources": ["japanese-wordnet", "ja-wiktionary"],
      "confidence": "high"
    }
  ],
  "wordConfidence": "high",
  "reviewRequired": false,
  "reviewReasons": []
}
```

`meanings` keeps broader dictionary-derived meanings for later wordbook features. `primaryMeanings` remains the short game-display candidate and is capped at three sense-level rows. `wordConfidence` is separate from per-primary-meaning confidence; it summarizes whether the whole word entry is ready for review-free use.

The full generator validates that all 2,500 master words are present, no duplicate words exist, level/source metadata is preserved, `primaryMeanings` has at most three entries, confidence values are valid, and no review-free word is missing primary meanings.
